## Deliberately excluded / not carried forward

- All React components, JSX/TSX, and the entire `app/ui/*.css` system — presentational, and the instruction was explicit that these are disposable regardless of quality.
- `react-transition-group` animation classes, the custom roving-`tabindex` carousel/tab implementations for About and Expertise, and the hand-rolled mobile-menu focus trap — all Next/React-specific interaction code. The redesign phase will need new, simpler disclosure/menu interactions built as small native scripts.
- `nuqs` (URL query-state library) — was used to mirror form input and the About/Expertise "topic"/"expanded" tab state into the URL. Dropped; not needed without the old tab UI. If deep-linkable Expertise sections are wanted later (the design brief calls for this), that can be done with plain anchor hashes.
- `@vis.gl/react-google-maps`, `@fortawesome/*`, `react`, `react-dom`, `react-transition-group`, `schema-dts` (kept the *shapes* schema-dts described, but not the package — JSON-LD objects are now plain typed literals in `src/data/`), `next`, `@next/bundle-analyzer` — all removed from dependencies.
- `pnpm-lock.yaml` — removed; project now uses npm per the new foundation's requirement, fresh `package-lock.json` generated.
- Stale `.env.example` Postgres/Auth.js template (see above).
